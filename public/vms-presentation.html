15 · SECURITY & RELIABILITY

Designed for real operational
failure modes.

01

Location isolation

Firestore rules reinforce the security boundary instead of relying only on UI filtering.

02

Atomic counters

Visitor serial generation uses transactions to prevent duplicate daily IDs.

03

Batch synchronization

Linked visitor/appointment and asset/pass state can be updated together.

04

Production hardening

Permission bugs, timeline crashes and webcam readiness issues were identified and corrected through real testing.
