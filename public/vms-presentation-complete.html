PRODUCT INTRODUCTION · VMS-SAIDHARA01 / 22
01 · WHY VMS

One operational picture
instead of disconnected records.

VMS-SAIDHARA is designed around what happens at a real industrial security desk: people arrive, officers change shifts, materials move, visitors leave, appointments are scheduled and management needs the history later.

01

Before the system

Visitor details, material movement, pass information and shift responsibility can become fragmented across paper, spreadsheets and informal handovers.

02

The VMS approach

Each operational action becomes a structured record connected to location, user role, officer, timestamp and related documents.

03

The result

A searchable digital trail for the front desk, security team, administration and management — without losing location boundaries.

Security rules

✓Public intake is restricted to valid VMS location IDs and creates only PENDING records.
✓Security reads appointments only for its own assigned location.
✓Appointment check-in requires an active security duty context.
✓Checkout synchronization prevents the appointment and visitor records from drifting apart.

17 · SECURITY & RELIABILITY

Controls are part of the product,
not an afterthought.

✓
Role-aware authentication

Firebase Auth establishes the signed-in identity used by the VMS authorization model.

✓
Location-safe access

Security users are constrained to their assigned location through Firestore authorization rules.

✓
Controlled public intake

Appointment creation is intentionally narrow: valid locations and PENDING state only.

✓
Atomic identifiers

Visitor numbering uses a Firestore transaction counter to avoid duplicate daily serials.

✓
Return synchronization

Shared batch logic updates linked asset and gate-pass return states together.

✓
Audit context

Officer names, actor IDs, timestamps and location metadata provide operational accountability.

✓
Storage controls

Visitor photos in the protected VMS flow use Firebase Storage with active-user checks.

✓
Deployment discipline

Source is versioned in GitHub and production delivery is managed through Vercel.
